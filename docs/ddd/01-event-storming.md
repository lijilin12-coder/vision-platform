## 🟪 规则（每当……就……）

| # | 规则 |
|---|---|
| P1 | 每当**检测已完成**，就按**采集策略**决定是否保存图像（→ E2） |
| P2 | 每当**检测已完成**，如果属于某个批次，就更新批次统计 |
| P3 | 每当**复判发现误判**，就把图像加入“待标注”数据集（→ E4） |
| P4 | 每当**模型已导入**，就自动依次执行量化 → 转换 → 验证（F3 → F4 → F6） |
| P5 | 每当**方案版本已发布**，就在目标平台上运行一致性验证（→ C4） |
| P6 | 每当**更新已就绪**，就在下一次检测开始前切换（→ G4） |
| P7 | 每当**切换后连续 N 次检测出现 ERROR**，就自动回滚（→ G6） |
| P8 | 每当**工位启动**，就加载上次生效的版本并预热模型（→ G1、G2） |

## 🟥 热点问题

| # | 问题 |
|---|---|
| H-01 | 算子升级后（比如参数变了），已经发布的方案怎么办？算子需要版本号吗？方案要记录它用的算子版本吗？ |
| H-02 | 方案引用的模型，在目标平台上没有对应格式的文件时，是在部署时拒绝，还是在运行时报错？ |
| H-03 | “结果一致”怎么定义？传统算法在不同平台上也可能有微小的浮点误差，容差定多少？哪些输出要比较（判定、测量值、缺陷位置）？ |
| H-04 | 热更新时，正在进行的检测用旧版本还是新版本？（初步想法：以检测**开始**时生效的版本为准） |
| H-05 | “工位”是什么？单机阶段只有一台电脑，还需要“部署到工位”这个概念吗？一台电脑可以同时运行多个工位吗？ |
| H-06 | 方案怎么从一个平台带到另一个平台？导出文件后手动拷贝，还是需要一个共享的方案仓库？ |
| H-07 | 平台内的标注工具做到什么程度？还是直接对接现成的开源标注工具？ |
| H-08 | 方案版本和模型版本是一起发布、一起热更新，还是可以各自独立更新？ |
| H-09 | 回滚时，是方案和模型一起回滚到上一个“组合”，还是可以单独回滚？ |
