## 这套教程怎么学

这套教程和 C++ 教程的结构相同：先提出问题，再讲思路，然后看代码、动手运行、做练习、自测。有三点不同：

1. **每个示例都会输出图像。** 图像处理要用眼睛看。示例不弹窗口，而是把每一步的结果保存成 PNG 文件，运行之后去输出目录里打开看。
2. **示例图像是程序画出来的。** 不依赖外部图片；而且因为是自己画的，圆在哪里、面积多少、转了多少度都是已知的，可以检查算法算得对不对。真实图像放在后面的练习和大作业里。
3. **每一课都要讲“什么时候不好用”。** 图像算法没有万能的，知道一个方法的适用范围比会调用它更重要。

### 大作业的初步设想

在一张图像里找出模板的位置和旋转角度，然后用这个结果把检测区域“摆正”。这是产线上最常见的第一步：零件每次放的位置和角度都不一样，后面的测量和缺陷检测都要先知道零件在哪里。

- **输入**：一张模板图像、一张待搜索的图像、角度范围。
- **输出**：中心位置（x, y）、角度、匹配得分；找不到时明确返回“没找到”。
- **分阶段完成**：
  1. 最直接的做法：把模板按固定步长旋转，每个角度做一次模板匹配，取得分最高的。能得到正确结果，但是很慢。
  2. 用图像金字塔加速：先在缩小的图像上粗略地找，再在原图上小范围精确地找。
  3. 提高精度：角度和位置做到小于一个步长（插值）。
  4. 处理实际问题：旋转后模板四角的空白（掩膜）、亮度变化、图像里有多个目标、目标不存在。
  5. 做成平台的算子，输出位置和角度供后面的算子使用。
- **评分程序**：教程提供一个程序，生成一批已知位置和角度的测试图像，自动给出位置误差、角度误差和耗时。目标初步定为：位置误差不超过 1 个像素，角度误差不超过 0.5 度。具体数值要等参考实现做出来之后再确定。
- 大作业会附带一份参考实现，建议先自己做完再看。

## 环境与运行

示例需要 OpenCV，和整个项目一起构建。先按 [构建说明](../../dev/build.md) 把项目编译通过，示例就已经一起编译好了。

运行某一个示例（以第 1 课为例）。macOS / Linux：

```bash
./build/docs/tutorial/opencv/examples/cv01_mat_basics build/tutorial-out/opencv/lesson01
```

Windows：

```bash
build\docs\tutorial\opencv\examples\cv01_mat_basics.exe build\tutorial-out\opencv\lesson01
```

命令行的参数是输出目录。运行之后打开这个目录看结果图像。

一次运行全部示例（它们同时也是测试）。macOS / Linux：

```bash
ctest --preset default -R "^cv"
```

Windows：

```bash
ctest --preset windows -R "^cv"
```

结果图像在 `build/tutorial-out/opencv/` 下，每课一个目录。

示例在自动构建里用 Windows（MSVC）和 Linux（GCC）编译并运行。macOS 上还没有验证过。

## 约定

- 示例共用的小工具在 [`examples/common/cvtut.h`](examples/common/cvtut.h)：输出目录、保存图像、生成示例图像、检查结果。
- 示例里每一条 `✓` 都是程序实际检查过的结论。教程正文里的数字来自示例的输出。
- 只使用 OpenCV 的 `core`、`imgproc`、`imgcodecs` 三个模块，和平台保持一致。不使用显示窗口的模块（`highgui`）。
