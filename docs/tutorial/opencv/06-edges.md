# 第 6 课：边缘

> 预计用时：3 小时
> 示例代码：[`examples/lesson06/`](examples/lesson06/)

## 这一课要回答的问题

前面三课的路线是“分割 → Blob”：先决定每个像素属于哪一类。这一课换一条路线：不问“这个像素是什么”，而问“**边界在哪里**”。

1. 边缘在图像里是什么？怎样找到它？
2. Sobel 和 Canny 分别做了什么？
3. 怎样把边缘的位置定到小于一个像素？
4. 测量尺寸为什么用边缘，而不用阈值加数像素？

## 1. 边缘就是亮度变化快的地方

沿一条水平线穿过零件的左边缘，把像素值打印出来：

```
x =         134 135 136 137 138 139 140 141 142 143 144 145 146
灰度：      169 169 169 169 164 139  98  74  69  70  70  70  70
相邻的差：     0   0   0  -5 -25 -41 -24  -5   1   0   0   0
```

- 背景上灰度是 169，零件上是 70，中间有几个像素的过渡（真实的镜头总有一点模糊，边缘不是“一刀切”的）。
- **相邻两个像素的差**在平坦的地方接近 0，在边缘处很大，最大的地方（−41）就是边缘的中心。
- 差是负的，表示从亮变到暗。

这个“相邻像素的差”就是数学上的**导数**（变化率）的离散版本，在图像处理里叫**梯度**。

**边缘 = 梯度大的地方。边缘的准确位置 = 梯度最大的地方。**

和阈值相比，梯度有一个本质的优点。把图像整体变暗到 60%：

```
光线变暗到 60%：变化最快的位置在 x = 139（原来 139），差值从 -41 变成 -24
```

**边缘的位置没有变**，只是梯度变小了。阈值看的是亮度的绝对大小，光线一变就不对了（第 3 课）；梯度看的是亮度的**变化**，哪里变化最快和光线强弱无关。

## 2. Sobel：整张图像的梯度

### 2.1 两个方向

图像是二维的，亮度可以沿 x 方向变化，也可以沿 y 方向变化，所以梯度有两个分量。

```cpp
cv::Mat dx, dy;
cv::Sobel(part, dx, CV_16S, 1, 0);   // x 方向：左右相邻像素的差
cv::Sobel(part, dy, CV_16S, 0, 1);   // y 方向：上下相邻像素的差
```

Sobel 是第 4 课讲的滤波，只是换了一个核。x 方向的核是：

```
-1  0  +1
-2  0  +2
-1  0  +1
```

每一行都是“右边减左边”，三行加权求和（中间一行权重大）。相比只用一行，它顺便在垂直方向上做了一点平滑，对噪声不那么敏感。

```
Sobel：左边缘 dx = -260，右边缘 dx = 252，上边缘 dy = -256，零件内部 dx = 9
```

| 位置 | dx | dy | 含义 |
|---|---|---|---|
| 左边缘（竖直的边，亮→暗） | 很大的负数 | 接近 0 | 亮度沿 x 方向下降 |
| 右边缘（竖直的边，暗→亮） | 很大的正数 | 接近 0 | 亮度沿 x 方向上升 |
| 上边缘（水平的边） | 接近 0 | 很大的负数 | 亮度沿 y 方向变化 |
| 零件内部 | 接近 0 | 接近 0 | 没有变化 |

注意：**竖直的边缘是 x 方向的梯度找出来的**，因为穿过它时是沿 x 方向走的。

### 2.2 输出类型必须能表示负数

第三个参数 `CV_16S` 是输出的类型：16 位有符号整数。梯度有正有负，8 位无符号数放不下。

```cpp
cv::Sobel(part, dx8, CV_8U, 1, 0);   // 错误：负的梯度全部变成 0
```

示例检查了后果：左边缘（负的梯度）完全消失，只剩右边缘（`06_sobel_dx_8bit_wrong.png`）。这是第 2 课“饱和”的直接后果，也是用 Sobel 时最常见的错误。读的时候用 `at<short>`。

### 2.3 梯度的大小和方向

把两个分量合起来：

```cpp
cv::magnitude(dxF, dyF, magnitude);   // 每个像素：sqrt(dx² + dy²)
```

**梯度的大小**表示变化有多快，不管朝哪个方向。打开 `06_gradient_magnitude.png`：零件的四条边、两个圆孔的边、划痕的边都是亮的，其余是黑的。

**梯度的方向**（`atan2(dy, dx)`）指向亮度增加最快的方向，它总是和边缘垂直。大作业的进阶部分会用到。

### 2.4 直接对梯度做阈值的问题

```
对梯度大小做阈值：左边缘有 4 个像素宽
```

边缘有几个像素的过渡带，过渡带里的梯度都不小，所以对梯度的大小做阈值，得到的是一条**带子**，不是一条线（`06_gradient_threshold.png`）。门限低了带子更宽、噪声也进来了；门限高了弱的边缘断掉。

## 3. Canny：一个像素宽的边缘

```cpp
cv::Mat edges;
cv::Canny(part, edges, 50, 150);   // 低门限 50，高门限 150
```

Canny（以提出者的名字命名）是最常用的边缘检测方法。它在 Sobel 的基础上多做了两件事：

**① 只保留梯度“最大”的那一个像素。** 沿着垂直于边缘的方向看，过渡带里的几个像素中只留下梯度最大的那一个，其余的去掉。结果是一个像素宽的细线。

```
Canny 的结果：左边缘正好 1 个像素宽
```

**② 用两个门限把边缘连起来。**

- 梯度大于**高门限**的：一定是边缘。
- 梯度小于**低门限**的：一定不是。
- 介于两者之间的：**只有和“一定是边缘”的像素连着时**才算。

这样一条边缘上即使有一段比较弱，也不会断开；而孤立的、弱的噪声点不会被留下。

```
Canny 找到 1929 个边缘像素；矩形加两个圆孔的周长约 1680
```

多出来的部分包括划痕两侧的边缘（`06_canny.png`）。

**门限怎么选**：高门限取“想保留的最弱的边缘”的梯度大小，低门限一般取高门限的三分之一到一半。先看一看 `06_gradient_magnitude.png` 里真正的边缘有多亮，再定。

**噪声**：

```
噪声较大的图像：直接 Canny 得到 74457 个边缘像素；先高斯滤波再 Canny 得到 1932 个
```

求差会**放大噪声**：相邻两个像素一个偏亮 10、一个偏暗 10，差就是 20。所以求梯度之前几乎总是先做一次高斯滤波（第 4 课）。对比 `06_canny_noisy.png` 和 `06_canny_noisy_smoothed.png`。

**Canny 的结果是什么**：一张二值图像，边缘像素是 255。它告诉你“这里有边缘”，但是：

- 位置只精确到整数像素；
- 不知道哪些边缘像素属于同一条边、是直线还是圆；
- 结果依赖两个门限。

所以 Canny 适合**看**边缘在哪里、作为后续处理的输入。要**测量**，用下面的办法。

## 4. 卡尺：把边缘定到小数位

### 4.1 问题：用阈值量宽度不准

示例图像是一根深色的长条，左边缘在 200.375，右边缘在 400.625，**真实宽度是 200.25 个像素**（`06_bar.png`）。边缘特意放在不是整数的位置上，这才是实际情况：零件的边不会正好落在两个像素之间。

第 5 课的办法是分割之后数像素：

```
  阈值 90：199 个像素
  阈值 120：201 个像素
  阈值 150：201 个像素
```

- 结果只能是整数；
- 结果**取决于阈值**：边缘有几个像素的过渡带，阈值取高一点，过渡带里的像素就多算进来一些。阈值从 90 到 150，宽度差了 2 个像素；
- 光线一变，同一个阈值量出来的宽度就变了。

假设 1 个像素对应 0.05 毫米，2 个像素就是 0.1 毫米。对精密零件来说这个误差太大了。

### 4.2 思路

**卡尺**（caliper）是测量类视觉软件里最基本的工具。做法是：

```mermaid
flowchart LR
    A["在边缘附近<br/>画一个小矩形"] --> B["垂直于测量方向<br/>取平均<br/>得到一条亮度曲线"]
    B --> C["求梯度"]
    C --> D["找梯度最大的位置"]
    D --> E["用左右两个点<br/>插值到小数位"]
```

第一步：**取一条亮度曲线，多行取平均。**

```cpp
// 第 y 行上下共 rows 行，逐列取平均
cv::reduce(image(cv::Rect(0, y - rows / 2, image.cols, rows)), averaged, 0, cv::REDUCE_AVG, CV_64F);
```

只用一行的话，噪声直接影响结果。边缘是竖直的，沿着边缘的方向取 21 行平均，噪声降到原来的 1/√21（第 4 课），而边缘的位置不受影响。

第二步：**求梯度，找最大值。** 和第 1 节一样。

第三步：**插值。** 梯度最大的那个点，加上它左右各一个点，三个点可以确定一条抛物线，抛物线的顶点一般不在整数位置上，这就是更精确的边缘位置。

```
梯度
  │        ·  ← 抛物线的顶点（真正的最大值）
  │      ●
  │    ／    ＼●
  │  ●
  └──┴────┴────┴──── x
    199  200  201
```

```cpp
const double a = gradient(best - 1), b = gradient(best), d = gradient(best + 1);
const double offset = 0.5 * (a - d) / (a - 2 * b + d);   // 顶点相对于 best 的偏移，在 -0.5～0.5 之间
return best + offset;
```

这是第 5 课“亚像素”的又一个例子：边缘所在的那个像素是“一部分背景、一部分零件”的中间灰度，这个灰度值里就带着“边缘在像素里偏左还是偏右”的信息。

### 4.3 结果

```
卡尺：左边缘 199.866，右边缘 400.12，宽度 200.255（误差 0.0045）
如果只取整数位置：宽度 200（误差 -0.25）
```

宽度误差不到百分之一个像素。

（位置 199.866 和 200.375 相差约 0.5，这不是误差，而是坐标约定：OpenCV 把像素的**中心**当作整数坐标，而画图时是按像素的**左边界**算的，两者相差半个像素。两条边缘相减得到宽度时，这半个像素正好抵消。这类“差半个像素”的问题在视觉代码里经常出现，量绝对位置时要留意。）

光线变暗：

```
光线变暗到 60%：卡尺量出 200.256；固定阈值 120 量出 640
```

卡尺的结果没有变。固定阈值把整行都当成了长条。

多行平均的作用（噪声较大的图像，在 10 个位置各量一次）：

```
只用 1 行，最大误差 1.40；21 行取平均，最大误差 0.15
```

### 4.4 极性和“找不到”

```cpp
enum class Polarity { BrightToDark, DarkToBright };
double findEdge(profile, from, to, polarity, minStrength);
```

- **极性**：只找指定方向的边缘（亮→暗，或暗→亮）。测一个零件的宽度时，左边缘和右边缘的极性相反。指定极性可以避免找到旁边不相干的边缘。
- **搜索范围** `from`、`to`：只在预期的位置附近找。
- **最小强度** `minStrength`：梯度达不到这个值，就返回“没找到”（−1）。

```
在没有边缘的地方找：返回“没找到”，而不是硬给一个位置
```

最后一点很重要。零件没放好、缺了一块时，测量工具应该明确报告“找不到边缘”，而不是在噪声里挑一个最大的当作结果。和第 3 课大津法的教训一样：**好的检测工具要能说“没有”。**

### 4.5 卡尺的局限

- **要先知道边缘大概在哪里、朝哪个方向。** 卡尺只在一个小范围里找。零件的位置每次都不同时，要先定位（第 8 课和大作业），再把卡尺放到相应的位置上。这就是“先定位，后测量”。
- **一次只量一个点。** 要量一条边是不是直的、一个孔是不是圆的，要在很多位置各放一个卡尺，再把找到的点拟合成直线或圆（练习 6）。
- **边缘两侧要有稳定的对比。** 表面反光、有纹理时，梯度最大的地方不一定是真正的边界。

## 5. 像素不是毫米

卡尺量出来的是 200.25 **个像素**。图纸上的尺寸是毫米。两者之间的换算关系（一个像素对应多少毫米）取决于相机、镜头和安装距离，需要通过**标定**得到：拍一个尺寸已知的物体（标定板），算出换算比例。

镜头还会有畸变（图像边上的直线拍出来是弯的），精密测量时也要通过标定来校正。

在平台的设计里，标定是一个独立的部分（标定上下文），而且标定结果属于具体工位的具体相机，因为每个工位的相机位置都不一样。标定的原理这套教程不展开，知道“测量结果要经过标定才能变成毫米”就够了。

## 6. 和平台的关系

平台现在还没有边缘和测量类的算子。按设计，测量任务和缺陷检测任务的结果是分开的：检测给出“合格 / 不合格”，测量给出数值和公差判断。

卡尺是测量类算子里的第一个，适合作为你写的第一个“有点分量”的算子：

| | |
|---|---|
| 输入 | 图像；一个矩形的搜索区域（ROI） |
| 参数 | 方向（水平或竖直）、极性、最小强度 |
| 输出 | 边缘的位置（数值）；没找到时节点执行失败并说明原因 |

把两个卡尺的输出相减就是宽度。在方案里这会是：`灰度 → 卡尺（左） + 卡尺（右） → 相减 → 公差判断`。

## 8. 练习

1. **手写 Sobel**：自己用两层循环实现 x 方向的 Sobel（注意输出用 `short`），和 `cv::Sobel` 的结果比较（最外面一圈除外）。
2. **Canny 的门限**：对 `06_part.png`，把高门限依次设成 30、150、400、800，低门限取它的一半。划痕的边缘在哪个门限下消失？零件的边缘呢？这说明划痕和零件边缘的梯度各是多少？
3. **竖直方向的卡尺**：示例里的卡尺只能沿水平方向找竖直的边缘。写一个沿竖直方向的版本，量出第 1 课零件图像的高度（真实值 260）。
4. **插值的效果**：用 `makeBar` 生成左边缘在 200.0、200.125、200.25、……、200.875 的 8 张图，分别量出左边缘的位置。画一张表：真实位置、不插值的结果、插值的结果。插值的误差最大是多少？
5. **模糊程度的影响**：把 `makeBar` 里的高斯模糊从 1.0 改成 0.5、2.0、4.0，测量误差怎样变化？边缘太锐利或者太模糊，哪一种对亚像素测量更不利？为什么？
6. **拟合直线**（进阶）：把长条稍微转一个小角度（比如 2 度）再画出来。在 10 个不同的行上各放一个卡尺找左边缘，得到 10 个点，用 `cv::fitLine` 拟合成一条直线，算出它的角度。和真实角度差多少？
7. **量圆孔的直径**：对第 1 课的零件图像，用水平方向的卡尺穿过左边圆孔的中心，量出直径（真实值 70）。如果卡尺的位置偏离圆心 5 个像素，量出来的是多少？这个误差能用几何算出来吗？
8. **设计卡尺算子**：按第 6 节的表格，写出卡尺算子的签名（输入、输出、参数，参考 `threshold.cpp` 里 `meta()` 的写法）。“没找到边缘”应该用哪种方式报告？它和“节点执行失败”“判定为不合格”是什么关系？参考设计文档里关于判定的规则，先写出你的想法再讨论。
