# 推理引擎与大模型推理优化教程

| 项 | 内容 |
|---|---|
| 读者 | 学完 [现代工程 C++ 教程](../cpp/README.md)（至少到第 14 课、14 延伸、15、16 课），想往 AI 推理、AI 基础设施方向发展 |
| 目标 | 弄清一个推理引擎内部在做什么：算子、计算图、图优化、内存规划、量化、后端适配；再弄清大模型推理特有的几项技术：KV Cache、投机解码、Continuous Batching、PagedAttention、FlashAttention |
| 做法 | 每一项技术都**自己用 C++ 写一个最小的版本**，测量它，再去对照真实框架的源码 |
| 终点 | 两个大作业任选：给本项目实现推理后端并加上图优化；或者把后半部分的部件组装成一个最小的大模型推理服务 |

## 这套教程是什么

推理引擎（ONNX Runtime、MindSpore Lite、llama.cpp、vLLM）读起来很难，原因不是某一段代码难，而是概念多：打开源码，满眼是图、遍、kernel、execution provider、block table，不知道它们各自在解决什么问题。

这套教程的办法是反过来：**先自己遇到问题，写一个几百行的最小实现解决它，再去看真实框架是怎么做的。** 自己写过一遍 KV Cache，再读 llama.cpp 里对应的代码，就只是在看“同一件事的工程版本”。

教程分两部分：

- **第一部分：推理运行时（第 1～7 课）**。用视觉模型（卷积网络）做例子，内容可以直接用在本项目里：项目的执行引擎本身就是一个图执行器，`InferBackend`、量化、NPU 适配都是项目计划里要做的事。
- **第二部分：大模型推理（第 8～13 课）**。本项目是视觉检测平台，用不到大模型的服务端技术，所以这一部分是独立的支线：从一个最小的 GPT 前向出发，逐个实现大模型推理优化的核心技术。

第 0 课说明这些内容和招聘要求的对应关系，以及这套教程给不了什么。

想按固定的节奏学完，并且配合真实框架和 GPU 上的实验，见 [六个月学习计划](study-plan.md)。

## 怎么学

每一课的结构和 C++ 教程相同：

1. **这一课要回答的问题**
2. **先看不这样做会怎样**，再讲做法，配可以运行的示例和实测数字
3. **和项目（或岗位要求）的关系**
4. **练习**：每课 2～5 题，要动手改代码
5. **自测题**：答得出来就可以进入下一课

每课大约需要 2～3 小时。**每一课是一个文件夹**，里面的 `README.md` 是正文，旁边是这一课的示例代码。

三点说明：

1. **示例只用 C++ 标准库。** 不需要显卡，不需要安装 PyTorch、ONNX Runtime。目的是看清原理：真实框架里的代码做的是同样的事，只是更快、情况更多。
2. **模型的权重是随机数。** 推理优化关心的是“算得快、占内存少、结果和优化前一致”，这些都不依赖权重有没有训练过。所以示例里的模型不会说人话，但耗时、内存、一致性的测量都是真实的。把真实权重装进去是大作业的一部分。
3. **正文里的数字都是实测的**，来自一台 4 核 2.1 GHz 的机器。你的结果会不同，看比例和趋势。

## 建议的学习顺序

- **只关心本项目的推理部分**：01 → 02 → 06 → 07，然后做大作业 A。03、04、05 在需要优化时再学。
- **目标是大模型推理岗位**：全部按顺序学。第一部分不要跳过：大模型推理框架同样由算子、图、内存管理、量化组成，第二部分只是在这上面加了大模型特有的东西。
- **时间很紧**：00 → 01 → 05 → 08 → 09 → 11 → 12，其余以后补。

## 运行示例

和 C++ 教程一样，整套教程是一个 CMake 项目，就在这个目录（`docs/tutorial/inference`）下：

```bash
cd docs/tutorial/inference
```

```bash
cmake --preset default
```

```bash
cmake --build --preset default
```

```bash
ctest --preset default
```

**只编译、运行某一个示例**。目标的名字是“l课号_文件名”，可执行程序都在 `build/bin/` 下。每一课的“动手运行”一节会给出这一课的目标名。

几点说明：

- **测量时间的示例单独打开了优化**（`CMakeLists.txt` 里标了 `OPTIMIZE`），其余示例是调试版本，并且在 macOS 和 Linux 上带着内存检查工具编译。原因见 C++ 教程第 13、14 课。
- **每个示例都会检查自己的结果**（例如“优化后的输出和优化前一致”），不一致时返回非零值，`ctest` 就会报告失败。做练习改代码之后，先跑一遍 `ctest`。
- 一条命令做完上面三步：macOS / Linux 上是 `bash docs/tutorial/inference/run_all.sh`，Windows 上是 `docs\tutorial\inference\run_all.bat`。

环境要求和 C++ 教程相同，见 [那里的说明](../cpp/README.md#环境)。
