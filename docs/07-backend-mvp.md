## 3. 不在后端 MVP 里的

- 前端（界面）。等上面五件做完再考虑
- 鸿蒙相关的一切（POC-3a、3b、4、6、7、8、10）
- 真正的相机。图像源先只有“目录里的图像”；相机属于范围外的“工业相机”和待做的 POC-7
- P1 里还没做的：对比评估、样本包、标注、复判
- 模型依赖的“声明 + 锁定”（H-08 的完整做法）

## 4. 做完之后是什么样

一台机器上的方案构建平台：搭方案（现在靠命令行或 HTTP 接口）、训练模型、调试、把方案版本和它用到的模板、模型打成一个方案包文件。
另一台机器上的产线运行平台：导入方案包，部署到工位；工位从一个目录里取图像，连续检测，每次的结果里有判定、缺陷的位置、测量值；可以热切换、回滚。
两边都通过 HTTP 接口操作，为前端准备好了。
